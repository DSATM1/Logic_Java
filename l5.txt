
Java Core Theory — 1: JVM, JRE, JDK

This is one of the most important Java interview topics.

1. JVM — Java Virtual Machine

JVM is responsible for running Java bytecode.

When you write:

System.out.println("Hello");

Java source code is compiled into bytecode:

.java
  ↓
javac
  ↓
.class (Bytecode)
  ↓
JVM
  ↓
Machine Code

The JVM makes Java platform independent.

2. JRE — Java Runtime Environment

JRE provides everything required to run a Java application.

JRE
 ├── JVM
 └── Java Libraries

Think:

JRE = Environment to RUN Java programs

3. JDK — Java Development Kit

JDK is used to develop and run Java programs.

JDK
 ├── JRE
 │    ├── JVM
 │    └── Libraries
 │
 └── Development Tools
      ├── javac
      ├── java
      └── javadoc

Think:

JDK = Tools to DEVELOP Java programs

Easy Way to Remember
JDK → Develop
JRE → Run
JVM → Execute

Or:

JDK > JRE > JVM


2. Why is Java Platform Independent?

This is a very common interview question.

Java follows:

Java Source Code
       ↓
    Compiler
       ↓
    Bytecode
       ↓
       JVM
       ↓
Operating System

The same .class bytecode can run on different operating systems because each OS has its own JVM.

For example:

             Java Bytecode
                  |
       ┌──────────┼──────────┐
       ↓          ↓          ↓
   Windows JVM  Linux JVM  macOS JVM

Therefore:

Java is platform independent because Java source code is compiled into platform-independent bytecode, which runs on a platform-specific JVM.

3. Compiler vs JVM
Compiler

javac converts:

.java → .class
JVM

JVM executes:

.class → Machine Code

Example:

javac Main.java

creates:

Main.class

Then:

java Main

runs the program.


4. What is Bytecode?

Bytecode is the intermediate code generated by the Java compiler.

Example:

Main.java
   ↓
javac
   ↓
Main.class
   ↓
Bytecode

The JVM understands and executes this bytecode.

5. Why is Java Not 100% Platform Independent?

This is a slightly tricky interview question.

Java bytecode is platform independent, but the JVM is platform dependent.

For example:

Windows → Windows JVM
Linux   → Linux JVM
macOS   → macOS JVM

So remember:

Java bytecode is platform independent; JVM is platform dependent.
