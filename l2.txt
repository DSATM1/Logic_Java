1. Variables & Data Types
Primitive data types
Non-primitive data types
Type casting
Wrapper classes

Example

int a = 10;

double c = 15.5;

2. Operators
Arithmetic
Relational
Logical
Assignment
Bitwise
Ternary

Example

int a = 10;
int b = 20;

System.out.println(a > b);
System.out.println(a + b);


3. Conditional Statements
if
if-else
else-if
switch

Logic Example

int marks = 85;

if (marks >= 90)
    System.out.println("A");
else if (marks >= 75)
    System.out.println("B");
else
    System.out.println("C");
4. Loops
for
while
do-while
break
continue

Example

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
