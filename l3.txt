
1. Input → Process → Output (IPO)

Every Java program follows this flow:

Input
   ↓
Process (Logic)
   ↓
Output


Example: Add two numbers

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int a = sc.nextInt();
        int b = sc.nextInt();

        int sum = a + b;

        System.out.println(sum);
    }
}
