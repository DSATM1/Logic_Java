
1. Input → Process → Output (IPO)

Every Java program follows this flow:

Input
   ↓
Process (Logic)
   ↓
Output


Example: Add two numbers

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int a = sc.nextInt();
        int b = sc.nextInt();

        int sum = a + b;

        System.out.println(sum);
    }
}


2. Decision Making

Choose different paths based on conditions.

int age = 20;

if (age >= 18) {
    System.out.println("Eligible");
} else {
    System.out.println("Not Eligible");
}

3. Repetition (Loops)

Repeat a block of code.

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

4. Number Manipulation Logic
Reverse a Number
int n = 1234;
int rev = 0;

while (n > 0) {
    int digit = n % 10;
    rev = rev * 10 + digit;
    n /= 10;
}

System.out.println(rev);

Logic

Get the last digit (n % 10).
Add it to the reversed number.
Remove the last digit (n / 10).
Repeat until the number becomes 0.


5. Array Traversal
int[] arr = {10, 20, 30, 40};

for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
6. String Traversal
String s = "Java";

for (int i = 0; i < s.length(); i++) {
    System.out.println(s.charAt(i));
}

7. Method Logic

Break your program into reusable methods.

public class Main {

    static int square(int n) {
        return n * n;
    }

    public static void main(String[] args) {
        System.out.println(square(5));
    }
}

8. Object-Oriented Logic
class Student {
    String name;

    Student(String name) {
        this.name = name;
    }

    void display() {
        System.out.println(name);
    }
}

public class Main {
    public static void main(String[] args) {
        Student s = new Student("Suraj");
        s.display();
    }
}
