
1. Input → Process → Output (IPO)

Every Java program follows this flow:

Input
   ↓
Process (Logic)
   ↓
Output


Example: Add two numbers

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int a = sc.nextInt();
        int b = sc.nextInt();

        int sum = a + b;

        System.out.println(sum);
    }
}

3. Repetition (Loops)

Repeat a block of code.

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

4. Number Manipulation Logic
Reverse a Number
int n = 1234;
int rev = 0;

while (n > 0) {
    int digit = n % 10;
    rev = rev * 10 + digit;
    n /= 10;
}

System.out.println(rev);

Logic

Get the last digit (n % 10).
Add it to the reversed number.
Remove the last digit (n / 10).
Repeat until the number becomes 0.


5. Array Traversal
int[] arr = {10, 20, 30, 40};

for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
6. String Traversal
String s = "Java";

for (int i = 0; i < s.length(); i++) {
    System.out.println(s.charAt(i));
}
