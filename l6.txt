
Java Core Theory — 2: Variables & Data Types

Before OOP and advanced Java, you need to be very comfortable with variables, data types, memory, and type casting.

1. What is a Variable?

A variable is a named memory location used to store data.

int age = 25;

Here:

int → data type
age → variable name
25 → value

Think:

int age = 25;
│   │     │
│   │     └── Value
│   └──────── Variable
└──────────── Data Type


2. Java Data Types

Java has 8 primitive data types.

Data Type	    Size	          Example
byte	        1 byte	        byte a = 10;
short	        2 bytes	        short a = 100;
int	          4 bytes	        int a = 1000;
long	        8 bytes	        long a = 10000L;
float        	4 bytes	        float a = 10.5f;
double	      8 bytes	        double a = 10.5;
char	        2 bytes	        char c = 'A';
boolean      	JVM-dependent*	boolean b = true;

*The Java Language Specification does not define a fixed storage size for boolean.
